How to use this page

Each skill already has a group (G1 to G8) from Step 2, shown in the editable Group column.

Workflow

  1. Stratify select picks N random skills per group and ticks them.
  2. Export selected downloads ticked skills. Save as select/output_select/selected_skills.csv for Step 4.

Other buttons

  • Export all downloads every shown skill.
  • Clear selection unticks all.
  • Reload default reloads the Step 2 file and drops changes.
  • Load another CSV opens a different file.
  • Reset filters clears search and dropdowns.

Columns

  • Group (G1 to G8): the group from Step 2. Editable if you need to fix one by hand.
  • Others come from ESCO.

Buttons and filters act only on filtered rows. Click a row for full details.
